# Finora — AI-Powered Personal Finance Management Platform

Act as a senior UI/UX designer and fintech product designer.

Design a complete, modern, production-ready personal finance management web application named **Finora**.

This is an AI-powered financial management platform that uses LLM technology to help users track income and expenses, automate recurring payments, scan QR codes, automatically categorize transactions, and analyze personal financial behavior.

The application also includes a separate Virtual Bank service that manages simulated account balances through API requests.

Your task is to design the complete frontend UI/UX, including authentication screens, application dashboard, all major feature pages, and reusable design components.

Do not design only a landing page or dashboard. Build a cohesive multi-page web application.

---

# 1. Design Philosophy

Create a premium fintech SaaS experience.

Visual direction:
- Modern and minimal.
- Professional financial dashboard.
- Clean and structured layouts.
- Elegant typography.
- Strong information hierarchy.
- Generous whitespace.
- Subtle shadows and borders.
- Rounded cards and modern components.
- Consistent iconography.

Color palette & Dual Theme Architecture:
- **Light Theme (Default):**
  - Primary: Deep Navy (#111827)
  - Secondary: Slate (#64748B)
  - Accent / Primary Action: Emerald Green (#10B981)
  - Background: Light Gray (#F8FAFC)
  - Surface: White (#FFFFFF)
  - Income: Green (#10B981)
  - Expenses: Coral/Red (#EF4444)
  - Warning: Amber (#F59E0B)
- **Dark Theme (Emerald Nocturne Mode):**
  - Background: Deep Navy (#051424)
  - Surface: Surface Container (#122131)
  - Accent: High-contrast Neon Emerald (#4EDEA3)
  - Seamless toggle between Light and Dark themes via the navigation bar.

Avoid excessive gradients, unnecessary animations, crowded layouts, and decorative elements that reduce usability.

The application must look like a real fintech product that could be launched as a commercial SaaS platform.

# 9. Virtual Bank

Design a separate simulated banking module.

IMPORTANT:
This is NOT a real bank.

Its responsibility is limited to managing simulated virtual balances through API operations.
In this architecture, the Virtual Bank API is hosted within Next.js App Router API route handlers (`/api/virtual-bank/*`) as a dedicated, decoupled service supporting balance check, credit (Add Money), debit (Withdraw/Deduct), and audit ledger history.

Main account overview:
- Virtual account balance.
- Account ID.
- Account status.
- Total money added.
- Total money deducted.

Main actions:
- Add Money (Credit).
- Withdraw Money (Debit).

Each operation should have a confirmation modal.

Fields:
- Amount.
- Description.
- Transaction reference.
- Confirm button.

Transaction history:
- Transaction ID.
- Operation type.
- Amount.
- Previous balance.
- New balance.
- Timestamp.
- Status.

Design this page as a modern digital wallet interface.

Clearly distinguish between:
1. Financial records stored in the personal finance application.
2. Actual balance changes performed by the Virtual Bank API.

Do not automatically deduct money when users create an expense record unless the user explicitly confirms the operation or an authorized automation executes it.

# 10. AI Assistant

Design an LLM-powered personal finance assistant connected to REAL AI.

AI Integration Architecture:
- Uses Google Gemini API (`@google/genai` via Next.js route handlers `/api/ai/chat`, `/api/ai/categorize`, `/api/ai/insights`).
- Configured via `GEMINI_API_KEY` in environment variables with optional client-side API key configuration/override in the Settings page.
- Feeds live user financial context (recent transactions, category spending, balance) into system prompts for accurate personalized answers.

Chat interface:
- Conversation history.
- Chat messages.
- Message input.
- Send button.

Create a polished conversational interface with clear differentiation between user and AI messages.
